## 🛠️ Session Work & Topics Covered

### 📌 Session 1 Assignment: Fundamentals & Array Processing

* **Problem 1: Exam Hall Seat Duplication Checker** (`ExamHallSeatChecker.java`)
  * **Scenario:** Scans seat numbers to flag duplicates using basic arrays and nested loops without using Java Collections[cite: 3].
* **Problem 2: Typing Speed Test Accuracy Checker** (`TypingAccuracyChecker.java`)
  * **Scenario:** Compares typed text against an original passage character-by-character to compute accuracy percentage and locate the first mismatch[cite: 3].
* **Problem 3: Traffic Signal Streak Analyzer** (`TrafficSignalStreakAnalyzer.java`)
  * **Scenario:** Analyzes traffic signal color logs (e.g., `"RRGGGYRR"`) to find the longest continuous streak of any single color[cite: 3].
* **Problem 4: Warehouse Inventory Balancer** (`WarehouseInventoryBalancer.java`)
  * **Scenario:** Computes total stock across two warehouse sections to verify balance and tracks the location of the highest single item count[cite: 3].
* **Problem 5: Movie Review Word Length Profiler** (`MovieReviewProfiler.java`)
  * **Scenario:** Splits review text into individual words and categorizes them into Short (1–4 letters), Medium (5–8 letters), or Long (9+ letters) counts[cite: 3].

### 📌 Session 2 Assignment: String Manipulation, Parsing & Maps

* **Problem 1: ATM PIN Length Validator** (`ATM_PIN_Length_Validator.java`)
  * **Scenario:** Verifies if a user PIN string is exactly 4 digits long using `length()` and conditional checks[cite: 2].
* **Problem 2: Word Reversal Encoder** (`WordReversalEncoder.java`)
  * **Scenario:** Splits a sentence into words, reverses each word using `StringBuilder`, and joins them while preserving word order[cite: 2].
* **Problem 3: Product Inventory CSV Parser** (`InventoryRec.java`)
  * **Scenario:** Parses raw CSV records (`"ProductName, SKU, Quantity"`), validates field counts, and prints formatted output[cite: 2].
* **Problem 4: Library ISBN Normalizer & Validator** (`LibraryNormalizer.java`)
  * **Scenario:** Normalizes raw codes by trimming and uppercasing the 3-letter publisher prefix, then validates character types using `Character.isLetter()` and `Character.isDigit()`[cite: 2].
* **Problem 5: Stop-Word-Filtered Word Frequency Report** (`FilteredWordFrequency.java`)
  * **Scenario:** Strips punctuation, filters out common filler words (stop words), counts unique word occurrences using a `HashMap`, and outputs results sorted by frequency in descending order[cite: 2].
